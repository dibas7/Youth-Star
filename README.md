# Hostel Meal Management System

A modern React Native Expo app for Android that helps a hostel warden manage daily meal planning and lets students confirm whether they will take breakfast, lunch, or dinner.

## Features
- Student dashboard with meal selection cards and deadlines
- Notice board for hostel announcements
- Warden dashboard with meal summaries and management overview
- Clean blue, white, and green UI for mobile screens

## Run locally
1. Install dependencies with `npm install`
2. Start Expo with `npm start`
3. Open the Expo app on your Android device or emulator

## Build for Android
Use Expo EAS or the Android build workflow once the Expo environment is configured.
